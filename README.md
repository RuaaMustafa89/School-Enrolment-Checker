The School Enrolment Checker uses KISS (Keep It Simple Stupid) principle, as the program uses if, elif and else statements to check if the student can enrol.
The code is easy to read as it has meaningful variable names such as age, distance etc.
Use 'and' to check multiple conditions at once (DRY principle)
One improvement would be to add input validation, to make sure the user enter numbers for age and distance.
